## 🔐 لوحة تحكم المهندس (Engineer Admin Panel)

يمكن للمهندس فتح صفحة [admin.html](./admin.html) أو الضغط على زر القفل 🔐 من أي صفحة للوحة الشرف:
- **ما يمكن للمهندس فعله بدون لمس الريبو:**
  1. ✏️ **تعديل درجات أي طالب مباشرة** (حضور، تاسكات، مشاركة) مع أزرار `+` و `-` سريعة.
  2. ➕ **إضافة طالب جديد** لأي مجموعة بضغطة زر.
  3. 🗑️ **حذف أي طالب** بسهولة.
  4. 📁 **إضافة مجموعة جديدة** أو **حذف مجموعة موجودة** أو تعديل اسمها وموعدها.
  5. 💾 **حفظ التغييرات فوراً** لتنعكس على لوحة الشرف تلقائياً.
  6. 📊 **تصدير واستيراد ملفات Excel (.xlsx / .csv)** بنقرة زر واحدة (لكل المجموعات أو المجموعة الحالية).
  7. 📄 **تحميل قالب إكسيل جاهز** لكتابة الدرجات ورفعها مباشرة.

## ✨ التصميم والعرض:
1. **على الكمبيوتر واللابتوب**: يظهر جدول متكامل وشامل وأنيق به كل الأعمدة والدرجات بوضوح مع إبراز أصحاب المراكز الأولى.
2. **على شاشات الموبايل**: يتحول الجدول تلقائياً لكروت متجاوبة تمنع أي تشويه أو سحب أفقي، مع إبراز التاج والميداليات ودرجات المعايير كبادجات ملونة مبهجة.
3. تم إلغاء أزرار التبديل غير الضرورية (مثل زر Auto view) ليبقى التصميم بسيطاً ونظيفاً ومركزاً.
